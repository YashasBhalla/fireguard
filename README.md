# FireGuard · Team 29 Synergy

FireGuard is a web based fire safety monitoring and robot control project. The included interface has seven reference driven pages plus a profile page. The Java simulator supplies demo telemetry and robot commands.

## Start

With Docker installed, run `docker compose up --build`, then open [http://localhost:3000](http://localhost:3000). The Java API is available at [http://localhost:8080/api/telemetry/latest](http://localhost:8080/api/telemetry/latest).

## Public hosting

`render.yaml` is a Render Blueprint configuration. Push this project to a GitHub or GitLab repository, then in Render choose **New → Blueprint**, connect that repository, and deploy the `fireguard-demo` service. The backend serves the static frontend and API from one URL. The demo uses in-memory simulated readings; a restart resets its history.

Without Docker, use Java 17+ and Maven 3.9+: `cd backend; mvn spring-boot:run`. Serve `frontend/src` using any static HTTP server. The dashboard polls telemetry every 15 seconds.

Demo portal credentials: `demo123` / `demo`. They are a frontend-only demo gate, not production authentication. Dashboard predictive risk and sensor trends are generated by the simulator for demonstration and are not suitable for real safety decisions.
